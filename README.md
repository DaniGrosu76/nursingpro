# nursingpro

Aplicație simplă care afișează o propoziție în limba norvegiană și arată traducerea în română atunci când treci cu mouse-ul peste text (sau îl selectezi cu tastatura).

## Cum se rulează
1. Deschide fișierul `index.html` într-un browser web modern.
2. Pune cursorul peste propoziția în norvegiană pentru a afișa traducerea dedesubt.

## Cum funcționează
- Conținutul este definit în `script.js`, unde poți adăuga ușor alte propoziții și traduceri.
- Efectul de afișare la hover/focus este controlat din `styles.css`, astfel încât traducerea să apară lin când utilizatorul interacționează cu textul.
